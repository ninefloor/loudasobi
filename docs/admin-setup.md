# 관리자 연결·인증

## 사이드바 추천 목록

- `/admin/sidebar`에서 공개된 활성 곡만 추천 목록으로 편집합니다. shadcn 기반 폼과 드래그 손잡이, 위/아래 버튼, 그룹 이동 선택을 제공합니다. 그룹은 1단계이며 이름(1~80자)·곡 순서·그룹 순서를 설정합니다.
- `loudasobi_sidebar_settings`의 단일 행(id=1) `layout_json`에 `{groups: [{id, name, musicIds}], ungrouped: []}`를 저장합니다. 공유 곡·가사·콜·곡별 설정은 수정하지 않습니다. MONOASOBI `0007_loudasobi_sidebar` 마이그레이션 적용 후 사용합니다.
- 공개 사이드바는 추천순이 기본이고 ‘발매일순’은 기존 `musics.id ASC` 순서를 그대로 사용합니다. 새 발매일 컬럼이나 날짜 추정은 추가하지 않습니다. 정렬 변경은 현재 선택곡·재생 상태를 바꾸지 않습니다.
- 새로 공개한 곡은 그룹 없음 끝에 기존 순서로 추가됩니다. 비공개·삭제 곡은 조회 시 제외합니다. 추천 목록을 다시 저장할 때 현재 공개곡만 저장하며, 제외된 곡의 과거 배치는 보장하지 않습니다.
- 그룹을 삭제하면 소속 곡은 그룹 없음 끝으로 이동하며, 곡 자체는 삭제하지 않습니다. 공개 화면에서 그룹 없음은 다른 그룹이 있을 때 ‘기타 곡’으로 표시합니다. 빈 그룹은 공개하지 않습니다.
- 그룹 이름은 사용자 입력 그대로 공통 표시하고 자동 번역하지 않습니다. 정렬 선택·기타 곡 라벨은 ko/ja/en을 지원합니다.
- 저장은 명시적이며 트랜잭션으로 전체 목록을 교체합니다. 모든 공개곡이 정확히 한 번 포함되어야 합니다. 리비전 충돌(다른 관리자의 정렬 변경 또는 공개곡 변경)은 409로 거부하고 초안을 보존합니다. viewer는 읽기만 가능합니다. 새 조회·쓰기 API에도 인증 및 동일 출처 검증을 적용했습니다.
- 드래그는 브라우저 기본 HTML drag/drop을 사용합니다. 터치 환경과 키보드에서는 이동 버튼·그룹 선택으로 같은 기능을 사용할 수 있습니다.

## 곡 설정과 인증

- `/admin`: 인증된 공유 곡 목록과 loudasobi 전용 YouTube ID·팬라이트·공개 여부·싱크 보정 설정. 관리자만 저장하며 viewer는 열람만 가능합니다.
- 동일 Turso DB에 서버에서만 연결합니다. 곡 설정은 loudasobi_music_settings, 콜은 loudasobi_call_guides에 저장하며 공유 제목·가사는 수정하지 않습니다.
- 공개 화면은 musics.deleted_at IS NULL 및 publish=true인 곡과 MONOASOBI 원본 lyric_tracks를 요청 시 직접 조회합니다. 비공개 자료는 클라이언트에 보내지 않으며, 오류 시 정적 데이터로 대체하지 않습니다.
- 설정 행이 없는 신규 공유 곡도 관리자 목록에 나타나며 비공개로 취급합니다. 저장 시 전용 설정을 생성합니다. 가사 편집은 MONOASOBI에서만 진행하며 별도 가져오기는 필요 없습니다.
- 최종 sync(초) = lyric_tracks.sync + loudasobi_music_settings.sync_offset. 추가 보정의 기본값은 0이고 양수는 늦게, 음수는 일찍 표시합니다. 원본 sync는 loudasobi에서 수정하지 않습니다.
- loudasobi_lyric_tracks는 기존 사본 보관용이며 더 이상 참조하지 않습니다. 콜 문서는 musics.id를 참조합니다. 2026-09-24 MONOASOBI ID 보존 코드 배포 및 기존 가사 35곡·1,999줄의 ID 보강을 완료했습니다.
- 팬라이트 영문 키와 hex 사전은 src/lib/fanlights.ts에 있습니다.
- 곡 BPM은 전용 설정의 nullable `bpm`(20~400)에 저장합니다. 새 박수/콜 패턴은 곡 BPM(미지정 시 120), 1박 단위 8칸·모든 박 선택으로 시작하며 기존 패턴은 바꾸지 않습니다. MONOASOBI의 `0006_loudasobi_bpm` 마이그레이션을 앱 배포 전에 적용해야 합니다.
- 공개 변경은 공개 화면을 다시 열거나 새로고침하면 반영됩니다. 이미 열려 있는 화면을 실시간으로 회수하는 기능은 없습니다.
- MONOASOBI의 환경 변수 중 `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, 선택적 `ADMIN_VIEWER_PASSWORDS`만 사용합니다.
- 로컬 값은 Git에서 제외되는 `.env.local`에 보관합니다. 배포 환경에도 동일한 키를 **서버 환경 변수**로 설정해야 합니다. NEXT_PUBLIC_ 접두사는 사용하지 않습니다.
- 기존과 같은 admin/viewer 권한, 8시간 HMAC 세션, HttpOnly·SameSite=Lax·운영 Secure 쿠키를 사용합니다.
- 쿠키 이름과 서명 용도는 loudasobi 전용입니다. MONOASOBI 로그인과 별개이며, 다른 사이트의 쿠키로 로그인할 수 없습니다.
- 로그인·로그아웃은 동일 출처 요청만 허용합니다. 리버스 프록시는 원래 공개 요청 URL을 보존해야 합니다.
- 향후 읽기 기능은 `requireAdminSession`, 쓰기는 `requireAdminWriteAccess`와 `rejectCrossOrigin`을 모두 적용합니다. 페이지 검사만 믿고 API 보호를 생략하지 않습니다.
- 로그인 시도 횟수 제한은 아직 앱에 추가하지 않았습니다. 외부 공개 배포 시 호스팅/WAF에서 로그인 경로의 요청 제한을 설정해야 합니다.
- 스키마는 런타임 조회용 부분 매핑입니다. 공용 DB의 마이그레이션은 MONOASOBI에서만 관리하며 여기서 drizzle push/generate/migrate를 실행하지 않습니다.
- 음원 ID는 전용 설정 테이블에서만 가져옵니다. 공용 music의 MV ID는 런타임 모델에서 제외했습니다.
- 운영 곡을 임의로 공개하지 않습니다.

## 콜 편집과 비공개 미리보기

- 콜은 박수·챈트·떼창 블록의 통칭입니다. 새 콜은 박수로 생성하고 우측 ‘콜 종류’에서 변경합니다. 종류 변경은 위치·연결 가사를 유지하며, 떼창에서 다른 종류로 바꾸면 선택 강조를 해제합니다. 타이밍이 없는 블록을 박수·챈트로 바꾸면 기본 박자 패턴을 적용합니다.
- 챈트 내용은 선택적 `labels: { ko, ja, en }`에 저장합니다. 공개 화면과 감상 미리보기의 locale에 맞춰 표시하며, 기존 labels 없는 문서는 단일 label을 그대로 표시합니다. 새 다국어 내용에서 비어 있는 언어는 다른 언어로 대체하지 않습니다. 기존 JSON 컬럼 확장이므로 DB 마이그레이션은 없습니다.
- 떼창 편집은 일본어 원문·한국어 독음·영어 독음만 제공합니다. 기존 kr/en 선택 기록은 읽을 수 있지만 공개 강조와 스냅샷 검증에서 제외하고, 선택 범위를 다시 편집하면 정리합니다. 공유 번역 가사 자체는 삭제하지 않습니다.
- 확대·축소는 ± 버튼 또는 Cmd/Ctrl+세로 드래그(위로 확대, 아래로 축소)를 사용합니다. 범위는 8–480px/초이며 버튼은 화면 중앙, 드래그는 누른 지점의 시간을 기준으로 유지합니다. 확대 드래그는 콜 추가·이동·가사 선택을 실행하지 않습니다.
- 상단에서 실행 취소·다시 실행·초안 복사·전체 저장, 싱크 보정 팝오버와 라이트/다크/시스템 테마를 제공합니다. 미리보기 언어만 ko/ja/en으로 바꿀 수 있고 관리자 문구는 한국어를 유지합니다.

- 곡 설정의 ‘콜 편집·비공개 미리보기’에서 `/admin/musics/[id]/guide`를 같은 창으로 엽니다. 저장하지 않은 곡 설정은 이동 전 확인합니다. 저장된 YouTube ID·싱크 설정을 사용합니다. 비공개 곡도 인증 후 미리볼 수 있습니다.
- 콜 편집 화면은 viewport 너비 1024px 이상에서만 제공합니다. 작은 화면에서는 안내 화면만 표시하며 창을 다시 넓히면 콜·싱크 초안을 복원합니다. 모바일 감상 화면에는 영향을 주지 않습니다.
- 왼쪽 원본 가사와 오른쪽 콜 트랙이 하나의 세로 시간축과 스크롤을 공유합니다. 가사는 읽기 전용입니다. 가사 클릭·Shift 범위 선택 후 생성하거나 오른쪽 빈 구간을 드래그해 간주에도 생성합니다. 겹치는 콜은 나란히 표시합니다.
- 블록 드래그와 ±0.01/0.05/0.1초 버튼은 시작·끝·내부 펄스를 함께 옮깁니다. 위아래 손잡이는 길이 조절입니다. 입력 필드 밖에서 Space는 재생/정지, ←/↑는 -0.01초, →/↓는 +0.01초 탐색입니다. MONOASOBI처럼 방향키 탐색 시 일시정지합니다. 버튼 포커스보다 우선하며 방향키는 블록을 옮기지 않습니다.
- 8카운트 패턴은 BPM·첫 박 위치·1박/반박 분할 및 체크 상태로 편집하며 끝까지 반복합니다. ‘선택 구간을 정확히 8박으로 맞추기’는 별도 동작입니다. 개별 펄스 모드는 막대 클릭 추가, 펄스 클릭 삭제, 현재 재생 위치 추가 및 숫자 편집을 지원합니다. 패턴을 개별 모드로 바꾸면 계산된 펄스를 보존합니다.
- 눈금과 입력은 react-player 재생 초 단위이며 DB는 최종 sync를 뺀 공통 시간 기준입니다. 상단 가사 싱크 추가 보정은 기존 sync_offset을 조절해 가사와 콜 전체를 함께 옮깁니다. MONOASOBI의 원본 sync는 수정하지 않습니다.
- 편집은 즉시 로컬 미리보기에 반영됩니다. ‘전체 저장’은 콜과 sync_offset을 한 트랜잭션으로 저장하며 YouTube ID·팬라이트·publish는 덮어쓰지 않습니다. 최근 100개 편집의 실행 취소/다시 실행 및 Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z를 지원합니다. 별도 임시저장 테이블은 없습니다.
- `guide_json.version=2`이며 각 cue에 독립 start/end를 저장합니다. lines 참조는 박수·챈트에서는 선택, 떼창에서는 필수입니다. 부분 떼창 selection은 한 줄 내부 UTF-16 start/end입니다. 펄스는 pulseTimes 또는 pattern(bpm/subdivision/firstOffset/steps) 중 하나만 원본으로 사용하며 패턴 모드의 pulseTimes는 빈 배열입니다.
- 타임라인은 원문과 한국어 독음을 기본으로 표시하며, 표시 선택에서 원문만/한국어 번역/한국어 독음/영어 번역/영어 독음으로 전환할 수 있습니다. 줄이 짧아 텍스트가 잘리면 확대하거나 마우스 툴팁·오른쪽 떼창 편집에서 전체 내용을 확인합니다. 번역·독음별 별도 시간 블록을 만들지는 않고 기존 가사/콜 시간축을 공유합니다.
- 떼창의 `textSelections`는 연결 가사 줄의 `lineId`, `field`(jp/jpReading/enReading), 전체 필드 스냅샷 `text`, UTF-16 `start/end`를 저장합니다. 각 줄·표시별 한 범위를 독립 선택하며 전체 강조/해제도 가능합니다. 선택하지 않은 언어로 범위를 자동 복사하지 않습니다. 여러 가사를 연결한 경우 각 줄을 따로 지정합니다.
- 기존 `selection`은 일본어 범위로 계속 읽고 표시합니다. 언어별 선택을 편집할 때 기존 범위를 `textSelections`에 보존해 옮깁니다. 공유 원문·독음이 변경되면 선택 스냅샷을 검증해 재선택/해제를 요구하며, 가사를 다시 연결하면 기존 선택 범위를 초기화합니다. 자료가 없는 필드는 선택할 수 없습니다. 공개 ko/ja/en 화면에서도 해당 표시의 강조만 렌더링합니다.
- 다국어 떼창은 기존 JSON 컬럼의 선택적 필드 확장으로, 별도 DB 마이그레이션이나 운영 데이터 일괄 수정은 필요하지 않습니다.
- 버전 없는 기존 문서는 줄 스냅샷의 시작·끝과 pulseTimes를 보존해 읽을 때만 v2로 변환합니다. 사용자 저장 전 DB는 바뀌지 않습니다. 떼창 참조가 삭제·재정렬되거나 원문이 바뀌면 재연결을 요구합니다. 원문 시간이나 번역만 바뀌어도 독립 콜 블록은 자동 이동하지 않습니다.
- 공개 플레이어는 가사가 없는 콜 구간에 표시용 간주 카드를 합성합니다. 공유 가사 테이블에는 쓰지 않습니다. 감상 미리보기와 타임라인은 같은 react-player를 사용합니다.
- 겹치는 콜 종류와 부분 떼창 범위를 함께 표시합니다. 박수·챈트는 적어도 하나의 펄스가 필요하고 떼창은 선택입니다. 각 카드에 종류를 명시하며 타이밍에만 펄스가 적용됩니다.
- GET/PUT `/api/admin/musics/[id]/guide`는 인증 및 private/no-store를 사용합니다. PUT은 admin 권한·동일 출처·가사 참조·선택 범위·펄스 유효성을 검증합니다. 가사/설정/콜 리비전이 변경되면 409로 거절하고 초안을 유지합니다. ‘초안 복사’로 보관 후 새로고침할 수 있습니다.
- 콜 JSON v2 자체는 추가 마이그레이션이 필요하지 않습니다. 곡 BPM 컬럼은 위 마이그레이션이 필요합니다. viewer는 읽기 및 재생만 가능합니다. 왼쪽 시간 눈금의 빈 공간까지 클릭해 재생 위치를 이동할 수 있습니다. 재생과 시각 QA는 사용자가 직접 진행합니다.
